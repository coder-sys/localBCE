gate_verify.exe: the signer's self-check for gate checkpoints (PQ signing M1); the payer's verifier is M2 and is not built

Lean/Lake executable `gate_verify` (root BlindLedger.Gate.VerifyCli), built from the
`lean/` sources whose manifest is recorded in tools/tcb_report.txt.
Stateless: input `root_pk (2592) || u32 BE cert length || KEY-CERT || signed checkpoint`;
output `GATE_VERIFY=ACCEPT` (exit 0) or `REJECT` (exit 1); exit 2 for malformed input.
ML-DSA-87 (FIPS 204 algorithm) verified by Lean code written from the standard
(Gate/MlDsa87.lean), not by AWS-LC; no validation is claimed.

commit tools/tcb_report.txt (it requires the in-tree build to equal the pins).
