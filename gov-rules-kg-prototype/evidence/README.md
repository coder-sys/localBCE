# Rules Evidence

This directory is reserved for reviewed, immutable source artifacts used by
canonical government rules. A canonical rule must name a relative file in this
directory and pin the SHA-256 digest of the file's exact bytes.

The current Claude web corpus has URLs and citation text but no captured source
artifacts. Its promotion-queue records therefore remain blocked. Do not add
credentials, private records, downloaded runtime state, or machine-generated
build outputs here.
