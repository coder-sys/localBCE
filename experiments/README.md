Owner: the experimental source tree. Purpose: route to active Native-v3 fixtures and label
retained research lanes. This file is not architecture or backend-selection authority.

- `native_v3_phase0/` and `native_v3_phase0_rust/`: five-directive canonical business KATs.
- `native_v3_trust_boundary/` and `native_v3_trust_boundary_rust/`: interactive framing,

are retained code evidence. Their former design claims are retired; the foundation and fixed-shape
lanes have no active README authority of their own. They cannot select a backend, qualify a suite,
authorize PHI or payments, or activate production.

Current authority is `ARCHITECTURE.md`, `docs/NATIVE_V3_ARCHITECTURE.md`,
`docs/DATABASE_ZK_ARCHITECTURE.md`, and `CURRENT_TASK.md`.

Their code and tests are read-only evidence until a separately reviewed replacement deletes the
corresponding property. The current authority for all retained lanes is the parent architecture and
the exact tests, not a legacy directory narrative.
