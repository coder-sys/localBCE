# Portal Font Sources

The portal bundles the Latin subsets required by its current English-language interface.

- IBM Plex Mono, weights 400, 500, and 600: SIL Open Font License 1.1; source: https://fonts.google.com/specimen/IBM+Plex+Mono
- Public Sans, weights 400 through 700: SIL Open Font License 1.1; source: https://fonts.google.com/specimen/Public+Sans
- Source Serif 4, weight 600: SIL Open Font License 1.1; source: https://fonts.google.com/specimen/Source+Serif+4

The files were fetched from the Google Fonts CSS API and are served locally by the portal at `/shared-static/fonts/`. The portal makes no request to Google Fonts at runtime.
