# Where the old status history lives

The current status is `STATUS.md` at the trunk root. Standing rules are in `CONSTITUTION.md`.
`docs/history/` holds byte-for-byte copies (taken 2026-09-24) of each old checkout's
`STATE.md`, `CURRENT_TASK.md` and `AGENTS.md` (plus `AGENTS.override.md` where one existed),
named `<checkout>-<file>`. `rightrail-provider-app-20260923` had no `CURRENT_TASK.md`.
`rightrail-financial-workflow-20260913-CURRENT_TASK-20260920.md` and
`rightrail-financial-workflow-20260913-STATE-20260920.md` are the older (2026-09-20)
committed versions of that checkout's files, which sat at the trunk root after the
consolidation; they were moved here verbatim on 2026-09-24.
The copies are frozen history: do not edit them; add new status to `STATUS.md` instead.
Raw run logs they cite live in `work/pq-wide-seed-native-20260913/build-filter-native/`.
Earlier instruction bodies are in the Driver's `work/instruction-history/`.
Retired research code and history are bundled in `work/_retired-research-20260924/`.
The original checkouts under `work/` remain untouched and are the authoritative originals.
